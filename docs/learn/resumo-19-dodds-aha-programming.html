AHA = "Avoid Hasty Abstractions" (cunhado por Cher Scarlett). Constrói sobre a máxima de Sandi Metz — "prefer duplication over the wrong abstraction" — como contrapeso ao DRY dogmático. A régua-irmã é WET ("Write Everything Twice"), na formulação de Conlin Durbin: "você pode se perguntar 'já não escrevi isso antes?' duas vezes, mas nunca três."

A frase de ouro de Dodds: "Optimize for change first." O raciocínio: requisitos futuros são desconhecíveis, então abstração prematura cria código frágil "que dobra sob novos casos de uso, acabando inchado de lógica condicional" (o mesmo apodrecimento de Metz). Em vez de abstrair na 1ª ou 2ª ocorrência, espere até o padrão aparecer em vários lugares e as semelhanças "gritarem por abstração" (Rule of Three). O anti-exemplo concreto dele: controllers AngularJS super-abstraídos com monkey-patching, "SUPER confusing" e arriscados de mexer — queria que tivessem ficado duplicados.

Dodds resolve a tensão dos outros dois docs de abstração a seu favor — com uma condição. A cautela dele é contra abstrair cedo (1–2 ocorrências). Seu caso tem 32 ocorrências reais (26 procedures + 6 guards) da mesma tradução. Não é hasty; é o oposto — a semelhança já está gritando há tempo. Pela régua WET ("nunca a terceira vez"), você passou da terceira dezenas de vezes.

"Optimize for change first" dá o argumento positivo pela extração aqui. Pergunte: e se o formato do erro do transporte mudar (novo campo no TRPCError, novo mapeamento de httpCode)? Hoje: editar 32 lugares. Com toTRPCError: editar 1. A abstração reduz o custo de mudança em vez de aumentar — que é exatamente o teste de Dodds. Isso a distingue da "abstração hasty", que otimiza pra um futuro imaginário; aqui a mudança é concreta e o ganho é medível (1 vs 32).

A condição (o que AHA barra): extraia só o que 32× provou — a tradução. NÃO extraia especulativamente um framework layers() "pra qualquer necessidade futura de boundary" — isso seria o hasty que Dodds ataca: abstrair pra requisitos desconhecíveis. Regra prática que sai daqui:

// AHA aprova (mudança concreta, 32→1, sem especulação):
export const toTRPCError = (e: DomainError) => new TRPCError({ ... });
export const runDomain  = <T>(fn: () => Promise<T>) => { ... };

// AHA barra (especulativo, otimiza pra futuro imaginário):
const layers = () => ({ domain: ..., cache: ..., audit: ... }); // YAGNI
